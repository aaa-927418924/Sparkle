# コマンドパレット（現在停止中）

軽量なWindows配布版を維持するため、コマンドパレットとローカルLLM/Embedding検索は現在無効化しています。

既存のクリップ・メモ・タスク・プロジェクト画面、各画面の検索、SQLiteデータ、プロジェクト専属AI/API機能はこの停止対象ではありません。

`requirements-ai.txt` は履歴上の案内として残していますが、Torch、Transformers、CUDA、Embeddingモデルをインストールする必要はありません。モデルファイルも配布EXEには同梱しません。

将来この機能を再開する場合は、軽量ビルドと既存機能への影響を確認したうえで、別途実装を復元してください。
