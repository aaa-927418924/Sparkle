外部Webアクセス

AndroidなどTailscaleに接続できる端末にはServe、Tailscaleアプリを入れられない端末にはFunnelを使えます。 Web入口とRemote MCPは別アクセスキーで管理します。Funnel Webでは443を共有し、Serve Web / AndroidではWebをServe 8443、MCPを公開Funnel 443へ分離します。

Funnel WebではWebとMCPが443番、Serve Web / AndroidではWebがServe 8443番、MCP用Funnelが443番を使用します。Android接続URLには:8443を付けます。
